## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/udaydomadiya08/my_portfolio.git

# Navigate to project directory
cd my_portfolio

# Start a local static server
npx serve .
# or
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in any modern browser.

## ⚡ Deploying to Vercel

### Option 1: Automatic via Vercel Dashboard (Recommended)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Select your repository: `udaydomadiya08/my_portfolio`.
3. Click **Deploy**. Vercel will automatically detect `vercel.json` and deploy within 15 seconds.

### Option 2: Using the Vercel CLI
```bash
npx vercel
# For production:
npx vercel --prod
```
